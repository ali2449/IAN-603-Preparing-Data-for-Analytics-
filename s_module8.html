Use PostgreSQL date/time vocabulary

PostgreSQL patterns

Use subtraction, INTERVAL, EXTRACT, DATE_TRUNC, AGE, TO_DATE, TO_TIMESTAMP, and TO_CHAR.

Do not teach as PostgreSQL

DATEADD and DATEDIFF are common in other SQL dialects but are not PostgreSQL functions.

ImportantThe concept may be portable across databases, but the function names are dialect-specific.

IAN 603 · Module 8 · Slide 29
Temporal foundation
Choose the type before choosing the function
date
Calendar date
A day on the calendar without a time of day.
timestamp
Date + local clock time
No time-zone interpretation is stored with the value.
timestamptz
An instant in time
Displayed according to a time zone.
interval
A duration
For example five days and six hours.
IAN 603 · Module 8 · Slide 30
Temporal foundation
Use date when the time of day does not matter
Examples
Birth date, reporting date, service date, academic due date.
Strength
Clear calendar semantics without unnecessary clock-time detail.
Caution
Do not store a date as arbitrary text if you need sorting or date arithmetic.
IAN 603 · Module 8 · Slide 31
Temporal foundation
Use timestamp for date plus clock time without zone meaning
Represents
A local date and time such as 2026-03-18 14:40.
Useful when
The application already knows the local context or time zone is not relevant.
Risk
A timestamp alone does not identify one global instant when time zones matter.
IAN 603 · Module 8 · Slide 32
Temporal foundation
Use timestamptz when the value represents an instant
Meaning
A specific instant that PostgreSQL can display in different time zones.
Typical use
Orders, events, logs, or transactions collected across locations.
Important
The displayed wall-clock value can change with the session time zone while the instant remains the same.

Which function should you start with?
Email domain
Which delimiter-based function is natural?
Month bucket
EXTRACT(MONTH) or DATE_TRUNC('month')?
Elapsed stay

When should TO_CHAR be used?
Reveal the reasoning
