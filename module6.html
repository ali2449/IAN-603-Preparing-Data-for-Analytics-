P1

Patient Comprehensive Profile

Practice

Create a comprehensive patient profile that includes demographic information, admission history, lab results, and prescriptions.

💡 Need a hint?
Hint 1: Start by selecting the basic patient information from the patients table.
Hint 2: Use LEFT JOINs to include all patients, even those without admissions, lab results, or prescriptions.
Hint 3: Consider using COUNT() with DISTINCT to avoid double-counting when patients have multiple records.
Hint 4: GROUP_CONCAT() can help combine multiple diagnosis or medication values into a single string.
Query results will appear here...
💡 Solution
-- Comprehensive Patient Profile SELECT p.patient_id, p.name, p.age, p.gender, COUNT(DISTINCT a.admission_id) as total_admissions, COUNT(DISTINCT l.test_id) as total_lab_tests, COUNT(DISTINCT pr.rx_id) as total_prescriptions, GROUP_CONCAT(DISTINCT a.diagnosis) as diagnoses, GROUP_CONCAT(DISTINCT pr.medication) as medications FROM patients p LEFT JOIN admissions a ON p.patient_id = a.patient_id LEFT JOIN lab_results l ON p.patient_id = l.patient_id LEFT JOIN prescriptions pr ON p.patient_id = pr.patient_id GROUP BY p.patient_id, p.name, p.age, p.gender ORDER BY total_admissions DESC, p.name;
P2

Department Performance Analysis

Practice

Analyze department performance by joining admissions with medical staff and calculating key metrics.

💡 Need a hint?
Hint 1: Focus on aggregating data by department from the admissions table.
Hint 2: Calculate average length of stay using date functions on admit_date and discharge_date.
Hint 3: Count distinct patients to avoid double-counting when patients have multiple admissions.
Hint 4: Use GROUP_CONCAT() to show all specializations available in each department.
Query results will appear here...
💡 Solution
-- Department Performance Analysis SELECT a.department, COUNT(DISTINCT a.admission_id) as total_admissions, COUNT(DISTINCT a.patient_id) as unique_patients, COUNT(DISTINCT ms.staff_id) as staff_count, ROUND(AVG(JULIANDAY(a.discharge_date) - JULIANDAY(a.admit_date)), 1) as avg_length_of_stay, GROUP_CONCAT(DISTINCT ms.specialization) as specializations FROM admissions a LEFT JOIN medical_staff ms ON a.department = ms.department GROUP BY a.department ORDER BY total_admissions DESC;

Project Task 1: Patient Care Timeline Analysis

Create a comprehensive timeline of patient care, showing admissions, lab tests, and prescriptions in chronological order.

💡 Project Solution
-- PATIENT CARE TIMELINE ANALYSIS WITH patient_timeline AS ( -- Admissions SELECT patient_id, admit_date as event_date, 'Admission' as event_type, diagnosis as event_details, department FROM admissions UNION ALL -- Lab Tests SELECT patient_id, test_date as event_date, 'Lab Test' as event_type, test_name || ': ' || result_value as event_details, NULL as department FROM lab_results UNION ALL -- Prescriptions SELECT patient_id, prescribed_date as event_date, 'Prescription' as event_type, medication || ' - ' || dosage as event_details, NULL as department FROM prescriptions ) SELECT p.name, p.age, p.gender, tl.event_date, tl.event_type, tl.event_details, tl.department FROM patient_timeline tl INNER JOIN patients p ON tl.patient_id = p.patient_id ORDER BY p.name, tl.event_date;

Project Task 2: Department Cross-Referral Analysis

Analyze how patients move between departments and identify common referral patterns.

Challenge Mode Active - Schema hidden, limited attempts remaining: 3
Department referral results will appear here...
💡 Project Solution
-- DEPARTMENT CROSS-REFERRAL ANALYSIS WITH patient_department_sequence AS ( SELECT patient_id, department, admit_date, LEAD(department) OVER (PARTITION BY patient_id ORDER BY admit_date) as next_department, LEAD(admit_date) OVER (PARTITION BY patient_id ORDER BY admit_date) as next_admit_date FROM admissions ) SELECT pds.department as from_department, pds.next_department as to_department, COUNT(*) as referral_count, ROUND(AVG(JULIANDAY(pds.next_admit_date) - JULIANDAY(pds.admit_date)), 1) as avg_days_between FROM patient_department_sequence pds WHERE pds.next_department IS NOT NULL AND pds.department != pds.next_department GROUP BY pds.department, pds.next_department ORDER BY referral_count DESC;
