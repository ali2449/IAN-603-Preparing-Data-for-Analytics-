String Functions

Text Data Manipulation

SQL string functions manipulate text data to address issues like case inconsistency, extra spaces, or formatting errors.

💡 Real-World Use: Clean patient names in healthcare databases, standardize product descriptions in retail systems, and format email addresses for marketing campaigns.

UPPER/LOWER

Basic

Converts text to uppercase or lowercase for consistency

UPPER(column_name)
LOWER(column_name)

TRIM/LTRIM/RTRIM

Basic

Removes leading/trailing spaces from text

TRIM(column_name)
LTRIM(column_name)

CONCAT

Basic

Combines multiple strings together

CONCAT(str1, str2, ...)

SUBSTRING

Intermediate

Extracts a portion of a string

SUBSTRING(column FROM start FOR length)

REPLACE

Intermediate

Replaces occurrences of a substring

REPLACE(column, 'old', 'new')

LENGTH

Basic

Returns the length of a string

LENGTH(column_name)

Date Functions

Temporal Data Manipulation

Date functions manipulate temporal data, extracting components or calculating differences for time-based analysis.

💡 Real-World Use: Calculate patient length of stay in hospitals, analyze seasonal trends in retail sales, and determine project timelines in business analytics.

EXTRACT

Basic

Retrieves specific parts of a date (year, month, day)

EXTRACT(YEAR FROM date)
EXTRACT(MONTH FROM date)

DATE_TRUNC

Intermediate

Truncates date to specified precision

DATE_TRUNC('month', date)

DATE Arithmetic

Basic

Add/subtract time intervals from dates

date + INTERVAL '7 days'
date2 - date1

CURRENT_DATE

Basic

Returns current date

CURRENT_DATE
