IN Operator - Set Membership Check

How IN Works:

Checks if a value matches ANY value in a list or subquery result. Returns TRUE if match found.

Example Logic:
patient_id IN (1003, 1004, 1006)
≡ patient_id = 1003 OR patient_id = 1004 OR patient_id = 1006

ANY/SOME Operator - Partial Set Comparison

How ANY Works:

Returns TRUE if comparison is true for ANY element in the set. SOME is alias for ANY.

Example:
age > ANY(30, 40, 50)
≡ age > 30 OR age > 40 OR age > 50

ALL Operator - Total Set Comparison

How ALL Works:

Returns TRUE only if comparison is true for ALL elements in the set. Most restrictive operator.

Example:

≡ age > 30 AND age > 40 AND age > 50

Challenge: Find Complex Patients

Find patients who meet ALL these criteria:

  • Have multiple admissions (>1)
  • Have abnormal lab results
  • Are prescribed multiple medications
  • Are above average age
Your results will appear here...
💡 Solution Approach
-- Complex patient identification using multiple operators (AlaSQL compatible) SELECT p.patient_id, p.name, p.age, (SELECT COUNT(*) FROM admissions a WHERE a.patient_id = p.patient_id) as admission_count, (SELECT COUNT(DISTINCT medication) FROM prescriptions pr WHERE pr.patient_id = p.patient_id) as medication_count FROM patients p WHERE p.age > (SELECT AVG(age) FROM patients) -- Scalar subquery AND (SELECT COUNT(*) FROM admissions a WHERE a.patient_id = p.patient_id) > 1 AND EXISTS ( -- EXISTS for abnormal labs SELECT 1 FROM lab_results lr WHERE lr.patient_id = p.patient_id AND lr.result_value > 150 -- Simplified threshold ) AND (SELECT COUNT(DISTINCT medication) FROM prescriptions pr WHERE pr.patient_id = p.patient_id) > 1 ORDER BY admission_count DESC, medication_count DESC;

Patient Readmission Analysis

Identify patients who were readmitted within 30 days of discharge.

💡 Solution
-- Find patients readmitted within 30 days (AlaSQL compatible) SELECT DISTINCT p1.patient_id, p1.name, a1.discharge_date as first_discharge, a2.admit_date as readmission_date, (a2.admit_date - a1.discharge_date) as days_between FROM patients p1 JOIN admissions a1 ON p1.patient_id = a1.patient_id JOIN admissions a2 ON p1.patient_id = a2.patient_id WHERE a2.admit_date > a1.discharge_date AND (a2.admit_date - a1.discharge_date) <= 30 ORDER BY p1.patient_id, a1.discharge_date;
P2

Medication Adherence Report

Practice

Find patients with multiple prescriptions and analyze their medication patterns.

Query results will appear here...
💡 Solution
-- Analyze medication patterns for patients with multiple prescriptions SELECT p.patient_id, p.name, COUNT(DISTINCT pr.medication) as total_medications, MAX(pr.prescribed_date) as latest_prescription, MIN(pr.prescribed_date) as earliest_prescription FROM patients p JOIN prescriptions pr ON p.patient_id = pr.patient_id GROUP BY p.patient_id, p.name HAVING COUNT(DISTINCT pr.medication) >= 2 ORDER BY total_medications DESC;

Project Task 2: Department Performance Dashboard

Analyze key performance indicators for each department including average length of stay, readmission rates, and patient volume trends.

Department performance results will appear here...
💡 Project Solution
-- DEPARTMENT PERFORMANCE DASHBOARD (AlaSQL compatible) SELECT department, COUNT(DISTINCT admission_id) as total_admissions, COUNT(DISTINCT patient_id) as unique_patients, AVG(discharge_date - admit_date) as avg_length_of_stay, COUNT(DISTINCT CASE WHEN admission_count > 1 THEN patient_id END) as readmitted_patients, ROUND( COUNT(DISTINCT CASE WHEN admission_count > 1 THEN patient_id END) * 100.0 / COUNT(DISTINCT patient_id), 2 ) as readmission_rate_percent FROM admissions a LEFT JOIN ( SELECT patient_id, COUNT(*) as admission_count FROM admissions GROUP BY patient_id ) patient_admissions ON a.patient_id = patient_admissions.patient_id GROUP BY department ORDER BY total_admissions DESC;

Project Task 3: Medication Safety & Efficiency Analysis

Identify potential medication safety issues, analyze prescription patterns, and evaluate medication adherence across patient populations.

Medication analysis results will appear here...
💡 Project Solution
-- MEDICATION SAFETY & EFFICIENCY ANALYSIS (AlaSQL compatible) SELECT p.patient_id, p.name, p.age, COUNT(DISTINCT pr.medication) as total_medications, COUNT(DISTINCT pr.medication) * 2 as complexity_score, CASE WHEN COUNT(DISTINCT pr.medication) * 2 <= 10 THEN 'LOW' WHEN COUNT(DISTINCT pr.medication) * 2 <= 20 THEN 'MEDIUM' ELSE 'HIGH' END as complexity_level FROM patients p JOIN prescriptions pr ON p.patient_id = pr.patient_id GROUP BY p.patient_id, p.name, p.age ORDER BY complexity_score DESC, total_medications DESC;
