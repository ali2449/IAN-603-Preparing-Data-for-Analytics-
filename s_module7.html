ALL
Every value
The comparison must succeed for every returned value.

IAN 603 · Module 7 · Slide 59
Assessment
Can you identify the inner-query contract?
age > (...)
What must the subquery return?
patient_id IN (...)
What result shape is needed?
EXISTS (...)
What information about the inner result matters?
a.patient_id = p.patient_id
Why is the subquery correlated?
Reveal the reasoning
age > (...) needs one scalar value. IN needs a one-column set. EXISTS only needs at least one row. Correlation occurs because the inner query refers to the current outer-row alias.
IAN 603 · Module 7 · Slide 60
Assessment
Which anti-match is safer when NULL may appear?
NOT IN
Can become UNKNOWN when the returned set contains NULL.
NOT EXISTS
Tests matching rows directly and avoids the classic NULL trap.
Rule of thumbFor “no matching related row,” NOT EXISTS is often the clearest starting point.

The contracts worth remembering

IN

EXISTS
Existence

ANY / ALL
Set comparison

Correlated
Outer-row dependent

Derived table
Intermediate rows
Aggregate or reshape first, then query or join.
