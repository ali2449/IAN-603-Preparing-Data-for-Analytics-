Stable fields arranged in rows and columns.

Flexible fields

Unstructured

No fixed table

Free text, images, audio, video, or documents.

Nominal

Different categories with no inherent order.

Ordinal

Categories with a meaningful order.

Interval

Numeric values with equal differences but no true zero.

Ratio

Numeric values with equal differences and a meaningful zero.

Continuous

Data organization

Structured data has a predefined schema

Stable fields

Rows follow a consistent set of columns.

Easy validation

Types and constraints can be defined in advance.

Common homes

Relational databases, data warehouses, CSV, and Parquet.

Running case: patients, encounters, and labs tables.

Data organization

Semi-structured data has labels but flexible shape

Keys and tags

Fields are named, so the record is not completely free-form.

Nested values

Objects and arrays can appear inside records.

Optional fields

Different records may contain different keys.

Common homes

APIs, logs, IoT streams, JSON documents, and data lakes.

Data organization

Unstructured content does not naturally arrive as rows and columns

Free text

Clinical notes, emails, reports, and social posts.

Images

Medical images, photographs, scanned documents.

Audio and video

Recordings, calls, speech, and monitoring streams.

Documents

PDFs and other files with layout and mixed content.

Preparation usually requires extraction: NLP, OCR, image processing, speech processing, or manual coding.

What does each variable mean?

03

What Does Each Variable Mean?

Measurement scale determines which comparisons, summaries, and operations are defensible.

Measurement scales

Start with the broadest split

Categorical

Values represent labels, groups, or ordered levels.

NominalOrdinal

Numeric

Values represent quantities for which arithmetic may be meaningful.

IntervalRatio
Measurement scales

A simple decision tree

What do the values mean?
Labels or groups?
No order → Nominal
Meaningful order → Ordinal
Quantities?
No true zero → Interval
True zero → Ratio
Use the tree as a reasoning aid, not as a substitute for domain knowledge.
Measurement scales

Nominal: different, not ordered

Examples

Blood type, device type, ZIP code, patient identifier.

Useful summaries

Counts, proportions, and mode.

Typical visuals

Bar charts and mosaic plots.

Do not

Interpret numeric-looking category codes as quantities.

Measurement scales

Ordinal: ordered, but gaps may be unequal

Examples

Triage level, education level, satisfaction 1–5, membership tier.

Useful summaries

Counts, median, percentiles, and IQR.

Typical visuals

Ordered bar charts and rank-aware displays.

Caution

Codes such as 0,1,2,3 do not prove equal spacing.

Measurement scales

A 1–5 response is usually ordinal

Caution: equal-looking numeric steps do not guarantee equal psychological distance.
Measurement scales

Interval: equal differences, no true zero

Example

Temperature in Celsius or Fahrenheit.

Meaningful

A five-degree difference has a consistent interpretation.

Not meaningful

Twenty degrees Celsius is not twice as hot as ten degrees Celsius.

Measurement scales

Ratio: equal differences and a true zero

Examples

Age, elapsed time, distance, weight, income, and event counts.

True zero

Zero represents the absence of the measured quantity.

Ratios

Four visits can meaningfully be described as twice two visits.

Step 2: make technical representation match the concept

Meaningful pandas dtypesPython example
from pandas.api.types import CategoricalDtype

encounters["sex"] = encounters["sex"].astype("category")

triage_order = CategoricalDtype(
    categories=["Non-urgent", "Urgent", "Emergent"],
    ordered=True
)
tier_order = CategoricalDtype(
    categories=["Bronze", "Silver", "Gold", "Platinum"],
    ordered=True
)

encounters["triage_level"] = encounters["triage_level"].astype(triage_order)
encounters["member_tier"] = encounters["member_tier"].astype(tier_order)
encounters["patient_id"] = encounters["patient_id"].astype("string")
