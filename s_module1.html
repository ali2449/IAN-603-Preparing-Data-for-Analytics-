Data organization

Three common forms of data

Structured

Predefined schema

Stable fields arranged in rows and columns.

Semi-structured

Flexible schema

Named fields exist, but records may be nested or different from one another.

Unstructured

No fixed table

Meaning is embedded in text, images, audio, video, or documents.

ImportantStructured does not mean clean, numeric, or analysis-ready.

IAN 603 · Module 1 · Slide 16
Data quality

A value can be valid but still inaccurate

Validity

Does it follow the rule?

A temperature of 44.0 °C may fall inside a documented 30–45 rule.

Accuracy

Does it reflect reality?

The same 44.0 °C value could still be a sensor or entry error.

Important distinction

Validity can often be automated with rules. Accuracy may require source verification or domain evidence.

Do not over-clean

An unusual value is not automatically incorrect.

IAN 603 · Module 1 · Slide 29
Variable meaning

Interval means equal differences without a true zero

Example

Temperature in Celsius

A five-degree change has a consistent meaning.

Meaningful

Differences

20 °C minus 10 °C is a 10-degree difference.

Not meaningful

Ratios

20 °C is not twice as hot as 10 °C.

IAN 603 · Module 1 · Slide 30
Variable meaning

Ratio means equal differences and a meaningful zero

Examples

Counts and physical quantities

Age, elapsed time, distance, weight, income, and event counts.

True zero

Zero means none

Zero visits means no visits; zero elapsed seconds means no elapsed time.

Ratios

Multiplicative comparisons

Four visits can meaningfully be described as twice two visits.

from pandas.api.types import CategoricalDtype

encounters["sex"] = encounters["sex"].astype("category")

triage_order = CategoricalDtype(
    categories=["Non-urgent", "Urgent", "Emergent"],
    ordered=True
)
tier_order = CategoricalDtype(
    categories=["Bronze", "Silver", "Gold", "Platinum"],
    ordered=True
)

encounters["triage_level"] = encounters["triage_level"].astype(triage_order)
encounters["member_tier"] = encounters["member_tier"].astype(tier_order)
encounters["patient_id"] = encounters["patient_id"].astype("string")

OneHotEncoderPython · VS Code style
from sklearn.preprocessing import OneHotEncoder

one_hot = OneHotEncoder(
    drop="first",
    sparse_output=False,
    handle_unknown="ignore"
)

sex_matrix = one_hot.fit_transform(encounters[["sex"]])
sex_columns = one_hot.get_feature_names_out(["sex"])
encounters[sex_columns] = sex_matrix
Run this in Jupyter, Colab, or VS Code.

Why handle_unknown?

It prevents unseen categories from automatically causing a transform error in many workflows.

PostgreSQL preview

Storage should support meaning and data-quality rules

Analytical meaning

Tells us whether a field is an identifier, category, count, measurement, or time value.

Storage requirement

Tells PostgreSQL how to represent values and what precision or constraints are needed.

Not identical

A nominal identifier may be stored as BIGINT, UUID, or TEXT.

Design goal

Choose types and constraints that preserve meaning and prevent invalid data.

IdentifierBIGINT, UUID, or TEXTDo not perform arithmetic just because an ID contains digits.

CountINTEGER or BIGINTUse nonnegative constraints when appropriate.
Exact decimalNUMERIC(p,s)Useful for money and exact arithmetic.
