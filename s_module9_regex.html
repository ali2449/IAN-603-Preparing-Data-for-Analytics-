Regular Expressions in PostgreSQL

Learn regex by changing patterns and running real PostgreSQL directly in the browser. Start with simple matching, then use regex to clean, validate, extract, and split messy text.

Big picture

Regex is a pattern language

Match

Ask whether text fits a pattern.

Transform

Replace matching text with something else.

Extract

Pull useful pieces from a larger string.

Important: regex can test structure. It does not prove that an email mailbox exists, that a phone belongs to a person, or that a value is semantically correct.

Quick reference

Patterns worth remembering

[0-9]one digit
[0-9]+one or more digits
^[0-9]+$digits only
[A-Za-z]+letters
[^0-9]not a digit
[[:space:]]+one or more whitespace characters
^Astarts with A
edu$ends with edu
(cat|dog)cat OR dog
[0-9]{3}exactly three digits
[0-9]{2,5}two through five digits
\mcat\Mwhole word cat in PostgreSQL
Return to Module 9: use these patterns for standardization and validation, but keep the larger cleaning principle in mind: detect uncertainty rather than inventing missing truth.
