Choose the pattern

CASE and FILTER can express similar logic

Use CASE when

You want broad portability or need flexible value mapping.

Use FILTER when

You are writing PostgreSQL and want concise independently filtered aggregates.

For this course: understand both. CASE is more portable; FILTER is often cleaner in PostgreSQL.

Subtotal NULLs

GROUPING() distinguishes subtotal placeholders from real NULL values

Subtotal rows often display NULL in grouped columns, but source data can also contain real NULL. GROUPING() tells you why the NULL is there.

Code 0

Both category and product participate.

Code 1 or 2

One expression is rolled up.

Code 3

Grand total row.

Do not rely on COALESCE alone when real NULL values are possible.

Logical execution

Understanding clause order explains many SQL rules

1FROM / JOIN
2WHERE
3GROUP BY
4HAVING
5SELECT
6WINDOW
7ORDER BY
8LIMIT
  • WHERE cannot use a same-level aggregate because grouping has not happened yet.
  • HAVING can test aggregates because the groups already exist.
  • Window functions see rows remaining after grouping and HAVING.
