Module 3: DQL/DML

5

Basic JOIN Operation

DQL/DML

Show student names along with the courses they are enrolled in.

💡 Hint
You need to JOIN students and enrollments tables, then JOIN with courses table.
Query results will appear here...
Sample Solution
SELECT s.first_name, s.last_name, c.course_name FROM students s JOIN enrollments e ON s.student_id = e.student_id JOIN courses c ON e.course_id = c.course_id;
6

Data Insertion

DQL/DML

Add a new student to the database with the following details:
First Name: "Alex", Last Name: "Johnson", Email: "alex.j@university.edu", Major: "Mathematics"

💡 Hint
Use INSERT INTO statement to add new records to a table.
Query results will appear here...
Sample Solution
INSERT INTO students (first_name, last_name, email, major) VALUES ('Alex', 'Johnson', 'alex.j@university.edu', 'Mathematics');

Module 4: Aggregations

7

Counting Records

Aggregations

Count how many students are in the database.

💡 Hint
Use COUNT() function to count the number of rows.
Query results will appear here...
Sample Solution
SELECT COUNT(*) FROM students;
8

Grouping Data

Aggregations

Count how many students are in each major.

💡 Hint
Use GROUP BY clause with COUNT() function.
Query results will appear here...
Sample Solution
SELECT major, COUNT(*) as student_count FROM students GROUP BY major;

Multiple Conditions

SQL Logic

💡 Hint
Use OR operator in WHERE clause to check multiple conditions.

Sample Solution
